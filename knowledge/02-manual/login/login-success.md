# Valid user login

## Steps

1. Open the login page.
2. Enter valid configured credentials.
3. Submit the login form.
4. Confirm that the user reaches the workspace home page.
5. Confirm that the workspace home title is visible.

## Expected result

The authenticated user reaches the workspace home page and sees its title.
