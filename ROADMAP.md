# Roadmap

This is a learning and reference project. The roadmap prioritizes useful, evidence-backed Playwright workflows over broad platform infrastructure.

## Completed

- Playwright UI and API automation.
- Role-based fixtures and cleanup.
- FastAPI + React practice application.
- Repository-local agent skills and `AGENTS.md` guidance.
- Deterministic static code graph and OKF knowledge bundle.
- Grounded Login product knowledge and verified testing knowledge.
- Controlled Login knowledge drift reporting.

## Current

- Improve onboarding and repository documentation.
- Keep knowledge and quality checks reproducible.
- Add CI coverage for framework, knowledge, and Playwright validation.
- Demonstrate honest agent-assisted workflows using existing capabilities.

## Next

- Add focused examples for UI/API, knowledge-backed investigation, and test maintenance.
- Add product-to-test coverage queries for existing scenarios.
- Improve durable failure and flaky-test knowledge from real evidence.
- Add contribution guidance and small starter tasks.

## Future

- Agent-assisted test generation.
- Agent-assisted Playwright failure investigation.
- Evaluation tasks comparing agent work with and without repository skills/knowledge.
- Additional grounded product scenarios after the Login foundation is stable.

The project will remain Playwright-focused and will not require a vector database, graph database, or external knowledge service for its core workflow.
